# PC MONITOR

На экране — пустой рабочий стол с белыми SVG и подписями **SHOP**, **SCAVENGER**,
**MESSAGES**. В правом верхнем углу — маленькая надпись `PALE.HORSE.BUILD_RUV`.
Иконки слегка подсвечиваются при наведении. Окон и дополнительных панелей нет.
Справа внизу находятся монета, подпись CREDIT и текущий баланс (изначально 20).
Начальное значение задаётся в Credits на компоненте `PcMonitorTerminal`;
из игрового кода баланс обновляется через `SetCredits(amount)`.

Когда игрок стоит рядом с монитором (ближе Interaction Distance) и смотрит на экран,
в центре появляется белая точка. **E** плавно подводит камеру к монитору
(длительность — Focus Duration), дальше двигайте мышью. **Escape** так же плавно
возвращает камеру. Курсор учитывает выпуклость и движущиеся волны изображения.
Окно Game должно получать ввод с клавиатуры.

`PCMonitorGlass.mat` регулирует выпуклость изображения, волны, свечение, яркость
и строки развёртки. Физическая выпуклость сохранена в `PCMonitorScreen.asset`.
Для повторного подключения: **Tools → Moon Game → PC Monitor → Apply CRT Desktop**.

Внешний вид рабочего стола: `UI/Desktop.uxml` и `UI/Desktop.uss`.
Подписи EN/RU: `UI/TerminalText.json`. По умолчанию используется английский;
на компоненте `PcMonitorTerminal` можно выбрать Russian или вызвать
`SetLanguage(TerminalLanguage.Russian)`.

Шрифт **PT Mono** поддерживает латиницу и кириллицу, включая Ё/ё. Все эти знаки
имеют одинаковую ширину. Исходный TTF получен из официального репозитория Google Fonts:
https://github.com/google/fonts/tree/main/ofl/ptmono

Шрифт используется по SIL Open Font License 1.1, которая разрешает включать его
в коммерческую игру при соблюдении условий лицензии. Полный текст находится в
`Assets/Fonts/PTMono/OFL.txt` и включается в сборки через
`Assets/StreamingAssets/ThirdPartyLicenses/PTMono-OFL.txt`.

Используются белые версии SVG из существующей папки `Assets/Icons`.

## Charge_Monitor

Белая надпись CHARGE на чёрном фоне использует тот же CRT-эффект. Короткое
мерцание выбирает случайную отдельную букву; порядок букв остаётся обычным.
`ChargeMonitorGlass.mat` задаёт вероятность, частоту и длительность мерцания,
а также остаточную яркость потускневшей буквы. Шейдер работает без отдельного
компонента обновления. Скруглённый контур исходной поверхности сохранён.
Повторное подключение: **Tools → Moon Game → Charge Monitor → Apply CHARGE Screen**.
