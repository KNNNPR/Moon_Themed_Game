# MoonFinder

В SHOP появилась программа MoonFinder за 40 CR: превью использует модель Meteorite.
Прокрутите список магазина колесом мыши. После покупки значок луны появляется
в центре рабочего стола. Откройте его и выберите профиль слева.

## Диалоги в Inspector

Откройте `Assets/Resources/MoonFinderContent.asset` либо меню
`Tools > Moon Game > MoonFinder > Edit Dialogue Content`.

- `Profiles`: имена, описания, четыре портрета, награда каждого персонажа.
- `Nodes`: реплика персонажа (`Reply`) на английском и русском.
- `Choices`: варианты ответа игрока. `Next` — ID следующего узла в этом профиле.
- `Emotion`: Neutral, Angry или Love. В Neutral персонажи периодически моргают.
- `Romance`: выдаёт награду профиля один раз при переходе в этот узел.
- `First Node`: ID первого сообщения.
- `Shuffle Choices`: перемешивает ответы при входе в узел (включено у Ловейн).
- `Apple Clicks Required`: количество нажатий на яблоко, по умолчанию 5. Счётчик в чате скрыт.

Кнопка `Validate dialogue links` проверяет ID и переходы. Генератор создаёт asset
только при его отсутствии; существующие тексты не перезаписывает. Язык меняется
общей настройкой языка игры. Обновление выбранного чата перечитывает текст из asset.

## Награды

- Катерина: ключи от `Garage_Door`. До ключей нет подсказки или подсветки ворот.
  После ключей `[E] Open` поднимает их вверх, повторное нажатие закрывает.
- Ловейн: действующая атака Cerberus-9 прекращается, новые атаки больше не начинаются.
  Для успеха требуется последовательность из восьми правильных ответов. Ошибки
  возвращают к началу через сердитую реплику; награда за ошибку не выдаётся.
- Яблоко: нажмите большую иконку в его чате 5 раз. На карте появляется одно
  большое яблоко с коллайдером.

Положение объекта `MoonFinder Rewards / Apple Spawn` в Hierarchy задаёт область
появления большого яблока. Компонент ищет свободный участок LAND рядом с точкой,
чтобы яблоко не появлялось на крыше здания. `Apple Height` меняет его высоту.
Редактор создаёт этот объект с Undo и помечает сцену изменённой; сохраните её обычным
способом вместе со своими правками. В Play Mode также есть автоматическое создание.

Покупка, история переписки и награды действуют в текущем запуске, как существующие
улучшения бота. Они сохраняются при закрытии приложения и выходе из монитора.
