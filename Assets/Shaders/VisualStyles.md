# Режимы изображения

В проекте доступны **Retro** (cel-shading + dithering из PunchCard0) и **Color ASCII**.
Начальный режим задаётся в VisualStyleSettings. Цвет символов берётся из сцены, яркость выбирает
один из 16 символов. Неподвижный рисунок не мерцает и не прокручивается.

## Переключение

- В игре / Play Mode: **F6**, когда окно Game получает ввод с клавиатуры.
- В редакторе: **Tools → Moon Game → Visual Style → Color ASCII** или **Retro Dither + Cel**.
- Начальный режим: `Assets/Resources/VisualStyleSettings.asset` → **Default Style**.
  Выбор через меню в Edit Mode также сохраняет начальный режим.
  Переключение в Play Mode действует только в текущем сеансе.

Оба режима работают в PC и Mobile URP. Каждый кадр исполняется только один
экранный эффект; ASCII получает изображение до dithering. Cel-материалы и свет
сцены используются в обоих режимах. Намеренно пустые слоты модели сохранены.

## Настройка ASCII

**Tools → Moon Game → Visual Style → Select ASCII Material** открывает
`Assets/Materials/Retro/ColorAscii.mat`.

| Параметр | Результат |
| --- | --- |
| Character Height | Размер символов в пикселях: 6 — плотнее, 8–10 — обычный размер, 12–16 — крупнее. |
| Character Brightness | Яркость цветных символов. |
| Scene Behind Characters | Сколько исходного изображения видно между символами; 0 — чёрный фон. |
| Local Color Detail | Сохранение мелких цветных деталей внутри одной ячейки. |
| Color Saturation | 1 сохраняет цвета; 0 делает изображение монохромным. |
| Character Density | Насколько быстро появляются более заполненные символы. |
| Empty Dark Cells | Порог, ниже которого символы в тенях скрыты. |
| Effect Intensity | 0 полностью отключает ASCII, 1 даёт полный эффект. |

Для меню настроек можно вызвать `VisualStyleSwitcher.SetStyle(VisualStyle.ColorAscii)`,
`VisualStyleSwitcher.SetStyle(VisualStyle.Retro)` или `VisualStyleSwitcher.ToggleStyle()`
из пространства имён `MoonThemedGame.Rendering`.
Методы компонента `UseColorAscii`, `UseRetro` и `Toggle` также подходят для UI Button.

Глобальный переключатель F6 создаётся автоматически при старте игры. Для мобильного
управления эти же методы можно подключить к кнопкам меню.

**Install or Repair** в меню Visual Style восстанавливает подключение к обоим
рендерам, сохраняя значения материалов и выбранный начальный режим.

## Лунная атмосфера

`Tools → Moon Game → Atmosphere → Select Settings` открывает
`Assets/Resources/LunarAtmosphereSettings.asset`.

- **Clear Distance** — чистая ближняя зона, сейчас 10 м.
- **Distance Density** — постоянная дымка, постепенно скрывающая даль.
- **Ground Density / Ground Height / Height Falloff** — дополнительная низкая пыль
  с плавным ослаблением по высоте; базовая высота слоя сейчас 2 м.
- **Saturation / Shadow Brightness** — сдержанная палитра и затемнение слабого света.
  Яркие источники сохраняют больше своего цвета.
- **Lighting Bands** — число ступеней cel-освещения, сейчас 3.
- **Ambient Multiplier** — вклад рассеянного освещения; сейчас 0.72.
- **Texture Simplification / Texture Levels** — упрощение тональных переходов текстур
  в cel-материалах, без изменения самих карт и назначений материалов.
- **Band Pattern Size** — крупность неподвижного узора на границах ступеней света.

Профиль работает в Scene View и в игре через существующий проход атмосферы PC/Mobile.
Из длины луча исключается объединение защищённых помещений базы. Дымка за окнами
сохраняется. Moon Dust добавляет более плотную холодную пыль, Radiation — зелёную
дымку с прежним ограничением непрозрачности и прежним влиянием на энергию.

Retro использует 10 уровней яркости, преимущественно упорядоченный Bayer-дизеринг
и увеличенную ячейку рисунка (**Ordered Pattern Cell Size**). Мелкое случайное зерно
ослаблено через **Grain / Ordered Pattern**. **Dither Brightness Instead of RGB**
связывает переходы каналов через яркость, уменьшая цветные крапинки в темноте.
**Quiet Deep Shadows** ослабляет рисунок в глубоких тенях, чтобы дальняя дымка
растворялась в темноте.

В Color ASCII появились **Distant Cell Thinning**, **Cell Thinning Starts / Ends**.
После 18 м символы становятся реже и проще, достигая максимального разрежения к 75 м.
Яркие ячейки сохраняются лучше. Цветные символы и переключение F6 остаются доступными.
Эффекты по-прежнему обходят stencil-маску читаемой записки.

`LunarAtmosphereValidation.Run` предназначен для отдельной batch-копии проекта:
снимки Retro/ASCII, погоды и интерьера, а также GPU-проверки глубины, перекрывающихся
защищённых помещений и неизменности рисунка. Результаты: `Logs/LunarAtmosphereCaptures`.
