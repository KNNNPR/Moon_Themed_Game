# First morning and repair note

`Assets/Resources/OperatorTutorialContent.asset` contains all four radio subtitles, their reading times, and both versions of the repair checklist. English uses **Operator A.**; Russian uses **Оператор Я.**. Text and timings can be edited in the Inspector.

On the first story entry to Operator, `OperatorRadioBriefing` waits for the existing bed wake-up, then gently turns the human camera toward the real Radio prop. Subtitles appear at the bottom, outside scene post-processing. Space or Escape skips the briefing. Movement, interaction hints, toolbox and Escape settings are blocked during the sequence; the developer console can pause it. Completing/skipping saves PlayerPrefs `palehorse.operator.radio-intro.seen.v1`. Later entries retain the ordinary bed animation but skip the radio briefing; endless mode does not play it. Aborting the scene or disabling the component restores control without marking an unfinished briefing seen. No recorded speech is supplied or radio music modified. To preview again in Play Mode, use the component's **Replay radio intro** context menu.

The Notes prefab retains its credentials. The existing scene instance **Notes (1)** / **Notes(1)** automatically prints the repair guide instead. `NotesCredentials.content` can explicitly select either version. Guide lettering fits a calibrated printable rectangle on the same paper mesh and keeps the existing PT Mono font/clear ink material. Reading with E uses the existing note inspection camera. The guide covers Messages orders, Scavenger collection, the initial two-part cargo limit, unloading, fitting/hammering, toolbox access, wrench/screwdriver gestures, the final test and crane collection.
