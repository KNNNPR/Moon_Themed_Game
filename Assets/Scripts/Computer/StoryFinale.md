# Run flow and AURINKO

The first successful evacuation costs zero. Further evacuations cost ScavengerRobotState.evacuationCost (15 by default). A failed or repeated request does not consume the free evacuation or charge twice. A run ends with YOU ARE FIRED / ВЫ УВОЛЕНЫ only if the rover is Offline, its current evacuation price exceeds the balance, and Crazy Cosmonauts has not been purchased. An installed game remains an escape from bankruptcy even during its real-time death cooldown.

The six existing repair jobs retain their types, distance tiers and rewards. The seventh, sequentially unlocked job is SCAV_BOT_AURINKO, based on the complete SCAV_BOT chassis. Its English/Russian letter, customer, thanks, credits and AppleJolly logo are editable in **Assets/Resources/StoryFinaleContent.asset**. It pays no repair bounty and does not request salvage.

On acceptance, the player's rover is hidden and its feed cannot connect. Once AURINKO lands, the delivery hull is disabled and the actual part colliders are restored for interaction. Each removable module has tightened fasteners. Hold LMB and drag the wrench left to loosen, right to tighten; release to reset the wrist. Shift is not required (the old Shift + right stroke remains compatible). Turn the screwdriver counter-clockwise to loosen. The final-order tool hints state these directions explicitly. After every fastener on a module reaches zero, aim at the module and press E. A carried toolbox wrench or screwdriver is stowed automatically. Other carried objects must be put away first. The loose-mount animation stops before the module slides out and becomes a physical, carryable spare. Reassembly and ordinary final diagnostics are disabled for this order. The chassis stays supported as wheels are removed.

Removing the last module shows Thank you / Спасибо тебе as a bottom-center subtitle over the live scene, with a soft fade over four seconds. It has no full-screen background, does not capture input, pause simulation, change focus or move the cursor; the crane can be called immediately. Dismissing the subtitle cannot unpause settings opened during it. Only a completed crane collection unlocks endless mode. Credits use the PC's shared CRT shading (yellow phosphor, curvature, soft waves and glow), the original AppleJolly SVG and staggered unnumbered credit rows, with APPLEJOLLYGARDEN first. Pointer hit testing follows the same CRT UV distortion, so the Continue/Menu buttons stay aligned. Continue returns to the same run, its balance, upgrades and apps, and restores the rover. Returning to MENU keeps the unlock in PlayerPrefs `palehorse.endless.unlocked.v1`.

Console **dismantle** instantly removes all remaining AURINKO modules, including an in-progress removal, and closes the console to show the subtitle. It requires the seventh order to be present and landed, creates each spare once, and does not bypass the crane or prematurely unlock endless. It is listed by help and Tab completion.

Console **end** in Operator skips the first six jobs without paying their rewards and immediately accepts/delivers the seventh order. It replaces an active ordinary order, preserves balance, upgrades and an existing saved endless unlock, and returns an endless run to the story finale. Repeating it while AURINKO is already present keeps that robot and its progress. It waits for an active crane collection to finish. It closes the console so the delivery can land; use **dismantle** afterwards to skip the manual work. The ending still requires crane collection.

MENU > Wake up opens Story Mode / Endless Mode / Back. Endless remains locked until the finale collection; a new endless run skips story rows and immediately offers randomized repair jobs. Selecting either mode starts a new Operator scene, preserving the existing wake-up animation. Run-local money, upgrades, purchases and free evacuation reset; the endless unlock remains. The story can always be replayed. The debug Complete Main Orders action explicitly unlocks endless as a testing shortcut.

StationStoryFlow owns the subtitle and full-screen ending screens. Credits and firing pause simulation, have priority over Escape settings/console/PC focus, and restore time scale and cursor on dismissal. The non-blocking thank-you subtitle fades automatically; credits allow Continue or Menu after their short entrance animation; firing offers Restart or Menu. The firing screen uses the same yellow phosphor, curved glass, soft waves, glow and vignette as the credits; its two buttons are hit-tested through the matching CRT UV distortion without an entrance delay. Animations use unscaled time.

Credits and firing have an off-screen content panel and a separate on-screen UI Toolkit Image that fills the viewport. Their CRT pass runs in LateUpdate and always restores RenderTexture.active; it does not draw into the screen from OnGUI. This prevents the paused-room frame from remaining visible when the off-screen texture becomes the active framebuffer. An unavailable CRT material falls back to the readable flat screen, and missing managed UI references after a script reload rebuild the presentation. A display-construction exception releases the modal pause rather than leaving gameplay locked.
