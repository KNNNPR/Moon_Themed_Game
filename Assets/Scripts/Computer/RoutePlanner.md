# Route-LINK

The free **MAP / КАРТА** application is installed on the Operator PC. Its icon is the supplied `Assets/Icons/map-svgrepo-com.svg`, tinted white in the SVG to match the other desktop icons. The reference is editable in `Assets/Computer/PCMonitorAssets.asset` (`mapIcon`).

The chart is an orthographic top-down GPU scan of visible static meshes, using `Resources/RouteSurfaceScan.shader`. Invisible collision boxes, disabled renderers, shadow-only meshes, transparent fog and moving characters/props are excluded. It uses a 768-pixel square scan by default (`surveyResolution`, 256–1024), shaded by surface normals and height in muted olive tones. It does not add cameras, colliders or world objects. The render target, command buffer and readback are released after capture. Map clicks read the scanned surface height instead of physics volumes. Base unloading/spawn and actual charging zones are always marked. White dots show only the live parts of the accepted repair order. The chart is a schematic, not an automatic navigation/pathfinding solution.

Gates, the bridge and the lift are discovered when the rover approaches their control points within `discoveryRadius` (30 world units) and 12 units vertically. Multiple lift controls share one discovery. Discovered points remain for this run, and their labels reflect the real mechanism's current open/lowered/top state. An unopened passage is not a guaranteed drivable shortcut. Main-menu/new-run scene loading resets discoveries and the waypoint with the rest of the run.

Left-click the chart to set one waypoint on real scenery; clicking near a required-part dot snaps to that part. Wheel or +/- changes scale; hold RMB to move the view; **FULL MAP / ВСЯ КАРТА** restores it. **CLEAR WAYPOINT / УБРАТЬ МЕТКУ** removes the target. An invalid click outside the surveyed world does not overwrite an existing marker. The dashed line is a direct bearing, not a promise of a traversable route through fences or terrain. The side panel reports actual battery charge and cargo capacity.

The waypoint persists when closing the application or leaving the PC. In SCAV_BOT's feed it appears as an amber dot with **WAYPOINT / МЕТКА** and distance, drawn by the same after-ASCII HUD path as order targets. A selected part's white dot is suppressed while the waypoint occupies that location. Long waypoint text is kept inside the viewport. Clearing the waypoint removes this HUD target as well.

Only one PC application handles pointer input at once. Opening the map closes other application windows, and opening those windows closes the map. The map blocks desktop icon click-through. Escape closes the map before exiting the computer. Rebuilding the terminal UI preserves the run's chart, discovery and waypoint state.
